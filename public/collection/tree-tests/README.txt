This directory contains a collection of trees for testing.
Please add to this as you encounter other useful cases, and add info in this file.

balanced-tree is a balanced tree with 14 nodes; not all have degree 2

bst_7-* is a collection of random binary search trees with 7 nodes; nodes appear in order of insertion

rn_* is a collection of random trees with 10 nodes with edges in random order; nodes are ordered by id

ub* is a collection of deliberately unbalanced trees with nodes and edges in unrelated random order
